# **Nobita Bot (Slack Bot)**

A custom slack bolt built in Javascript and node. It is hosted by Nest.

---

# Slash Commands

* `/nobita-help` - To see all slash commands.
* `/nobita-ping` - Check bot latency.
* `/nobita-catfact` - Get a cat fact.
* `/nobita-joke` - Tells a joke.
* `/nobita-fact` - Tells a fact.
* `/nobita-coinflip` - Flips a coin.
* `/nobita-rolldice` - Rolls a die.

---

# How To Use

Go to this hackclub slack channel - https://hackclub.enterprise.slack.com/archives/C0BU5FX1ANN. It will redirect you to a slack channel "nobita-bot-demo". Try the following slash commands mentioned above.
