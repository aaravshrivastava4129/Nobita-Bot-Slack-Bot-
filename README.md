# **Nobita Bot (Slack Bot)**


Nobita Bot is a custom Slack bot built with **JavaScript** and **Node.js**. It is hosted on **Nest**.
The bot provides several simple slash commands for interacting with Slack, such as getting facts, jokes, cat facts, flipping a coin, and rolling a die.

---

# Slash Commands

* `/nobita-help` - To see all slash commands.
* `/nobita-ping` - Check bot latency.
* `/nobita-catfact` - Get a cat fact.
* `/nobita-joke` - Tells a joke.
* `/nobita-fact` - Tells a fact.
* `/nobita-coinflip` - Flips a coin.
* `/nobita-rolldice` - Rolls a die.

## Why I Made This Bot

I made Nobita Bot to learn how Slack bots work and to experiment with building an interactive bot that can respond to commands inside a Slack workspace.
I wanted to understand how a bot can receive commands from users, process them using JavaScript, and send a response back to Slack.

---

## How I Made It

The bot was built using:

- **JavaScript** — Main programming language
- **Node.js** — Runtime for the bot
- **Nest** — Used to host the bot

The bot works by receiving a slash command from Slack, processing the command using JavaScript and Node.js, and then sending the appropriate response back to Slack.
